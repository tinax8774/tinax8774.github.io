SEP11 freedom project

Context:My freedom project which was a year long project is based on giving books and movies suggestions for the user.

Content: This project is based on giving the user movies and book suggestions based off their emotions, traits, hobbies or careers and if they want a even bigger variety they can choose all of them. All books and movie titles are randomly generated and they are just suggestions so people can choose to find titles similar to that if they don't want any of the suggested titles.

Challenges: Some of the challenges was coding the main website because I had a lot of books and movie names which made it hard to piece everything together as there was way too many arrays and putting everything into the array was probably the biggest challenge. Another challenge was time as this was due at the end of spring break and trying to balance all my other classes and trying to finish this project took a huge chunk of my break.

Next Steps:For the next project I'm gonna try and take more time to make the project as my project this year was kinda plain as I did not have that much time for it.
